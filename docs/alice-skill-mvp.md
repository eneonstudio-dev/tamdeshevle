# Алиса → Бай: MVP webhook

Цель первого контура: дать Алисе голосовой вход в Бая без изменения существующего браузерного `bai-agent-core`.

## Архитектура

`Алиса → alice-bai-webhook → prices.json → сравнение корзины → ответ Алисе`

Первый контур намеренно использует текущий учебный `prices.json`. Он проверяет диалог, состояние корзины и расчёт, но не выдаёт эти цифры за live-цену магазина.

## Webhook

После деплоя Edge Function:

`https://cxpneczhczashanbetgj.supabase.co/functions/v1/alice-bai-webhook`

В Яндекс Диалогах создайте приватный навык и укажите этот адрес в **Backend → Webhook URL**. Включите **Хранилище**, чтобы `session_state` возвращался в следующих репликах.

После создания навыка задайте секрет/переменную окружения Edge Function `ALICE_SKILL_ID=<skill_id>`. Обработчик начнёт отклонять запросы с другим `session.skill_id`.

## Что уже понимает MVP

- `собери молоко, яйца, хлеб и курицу`
- `добавь макароны`
- `убери хлеб`
- `покажи корзину`
- `сравни`
- `очисти корзину`
- `что ты умеешь`
- `выход`

Поддерживаемые на первом шаге товары: молоко, хлеб, куриное филе, бананы, подсолнечное масло, яйца, гречка, сметана, сахар, макароны.

## Проверочный запрос

```json
{
  "meta": {
    "locale": "ru-RU",
    "timezone": "Europe/Moscow",
    "interfaces": {"screen": {}}
  },
  "request": {
    "command": "собери молоко яйца хлеб и курицу",
    "original_utterance": "собери молоко яйца хлеб и курицу",
    "type": "SimpleUtterance"
  },
  "session": {
    "new": true,
    "message_id": 0,
    "session_id": "local-test-session",
    "skill_id": "replace-with-real-skill-id",
    "user_id": "local-test-user"
  },
  "state": {},
  "version": "1.0"
}
```

На текущих учебных данных ожидаемый лучший вариант для Москвы:

- молоко: Магнит 95 ₽
- яйца: Магнит 99 ₽
- хлеб: Магнит 59 ₽
- куриное филе: Магнит 349 ₽
- итог: **602 ₽**

По текущему учебному набору разбивка этой конкретной корзины по магазинам не даёт дополнительной экономии.

## Проверка health-check Алисы

Если `request.original_utterance` равен `ping`, функция сразу отвечает `pong`, не загружая цены и не вызывая другие сервисы.

## Следующий этап

После того как приватный навык стабильно проходит тест Диалогов:

1. подключить live price-source layer;
2. нормализовать реальные SKU к товарным намерениям Бая;
3. добавить географию/точку магазина;
4. учитывать доставку, минимальную сумму и персональные скидки отдельно;
5. вынести общий shopping brain так, чтобы сайт и Алиса использовали один серверный контракт.
