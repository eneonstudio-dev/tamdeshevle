# Bai Language Corpus

Цель — держать Бая простым, но не тупым: любые изменения `bai-brain.js` можно проверять на стабильном наборе обычных русских фраз.

## Источник подхода

Корпус вдохновлён структурой **Amazon MASSIVE**: отдельные intent + slot-подобные сущности, много перефразировок и разговорных формулировок. MASSIVE содержит более 1 млн utterance на 51/52 языках (в зависимости от версии), включая `ru-RU`, с intent- и slot-разметкой. Лицензия исходного датасета — CC BY 4.0.

- Project: https://github.com/alexa/massive
- Amazon Science overview: https://www.amazon.science/blog/amazon-releases-51-language-dataset-for-language-understanding
- License/notice: https://github.com/alexa/massive/blob/main/NOTICE.md

Мы **не тащим весь MASSIVE в runtime и не копируем его целиком**. Тестовые фразы в `tests/bai-language-corpus.json` — короткий доменно-адаптированный набор для покупок: добавить, убрать, заменить, только, количество, бюджет, люди, дни, магазин, предпочтения, reset/undo, контекст и неясные команды.

## Запуск

Никаких npm-зависимостей:

```bash
node tests/bai-language-smoke.js
```

Runner поднимает `bai-brain.js` в Node `vm`, подсовывает минимальный mock `TDShoppingState`, прогоняет независимые кейсы и многошаговые диалоги и завершает процесс с кодом `1`, если есть регрессии.

## Правило развития

Когда Бай тупит на реальной фразе, сначала добавляем её (или обезличенный эквивалент) в corpus как регрессионный тест, затем чиним parser. Не добавляем новый «умный слой», если проблему можно закрыть маленьким детерминированным правилом.
