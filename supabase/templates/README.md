# Письма «Там Дешевле»

В hosted Supabase шаблоны устанавливаются в Dashboard → Authentication → Email Templates.

| Раздел | Тема | Файл |
| --- | --- | --- |
| Confirm signup | `Добро пожаловать в «Там Дешевле»` | `confirmation.html` |
| Magic Link | `Вход в «Там Дешевле»` | `magic-link.html` |

Оба шаблона используют `{{ .ConfirmationURL }}`. Не заменяйте переменную статической ссылкой.

Для полного удаления Supabase из отправителя нужен собственный SMTP и доменная почта. До подключения SMTP меняется содержание и тема письма, но технический отправитель остаётся провайдером Supabase.
