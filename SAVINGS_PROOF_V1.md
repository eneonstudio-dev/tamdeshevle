# Savings Proof v1

Savings Proof показывает только подтверждённую экономию.

- Экономия записывается, когда пользователь применяет более дешёвый вариант в Comparison Result v2.
- Запись разрешена только если весь выбранный вариант проходит Trust Layer как подтверждённый свежими ценами.
- Базой сравнения служит вариант той же корзины в одном магазине.
- Повторное применение той же корзины в тот же день не создаёт дубль.
- В профиле показываются: за 7 дней, за 30 дней, за всё время, число подтверждённых решений и лучшая экономия.
- Все данные хранятся локально в существующем `td:savings-ledger`.
- Никаких платных API и фоновых сервисов не используется.
