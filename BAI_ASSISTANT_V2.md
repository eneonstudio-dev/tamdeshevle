# Bai Assistant v2

Bai now behaves as a proactive shopping assistant rather than a command parser.

- asks for missing high-impact constraints instead of guessing;
- offers 2–4 suggested replies when several good paths exist;
- keeps basket context while refining budget, people, cooking effort and preferences;
- can advise on the current basket and suggest what to do next;
- supports a hands-free Dialogue mode: listen -> silence -> submit -> answer -> listen again;
- product prices and final optimization remain deterministic in the existing shopping engine.
