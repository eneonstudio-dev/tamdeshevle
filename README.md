# Votonobay

Votonobay — умный интерфейс для продуктовой корзины: собери список один раз и сравни варианты по цене, удобству и подтверждённости данных.

Рабочий сайт: https://eneonstudio-dev.github.io/tamdeshevle/

## Сейчас умеет

- Москва / Санкт-Петербург — разные ценовые данные и контексты
- Пятёрочка, Магнит, Перекрёсток, Лента, Дикси
- Доставка: Лавка и Впрок
- Корзина и сравнение вариантов целиком
- Режимы «сходить / привезти»
- Выбор конкретной физической точки магазина
- Карта ближайших магазинов
- Переход в официальные сайты сетей без ложного обещания автопереноса корзины
- Сохранение корзины в браузере

## Про цены

Votonobay разделяет подтверждённые цены и ориентиры. Если для товара или конкретной точки нет подтверждённой цены, отсутствующее значение не считается как 0 ₽ и неполный вариант не выдаётся за подтверждённый итог.

Точная цена и наличие перед покупкой подтверждаются магазином.

## Бренд

Мастер-бренд проекта — **Votonobay**. Принцип интерфейса: не только «где дешевле», а «как лучше собрать корзину» с учётом цены, удобства и качества данных.
