# Тамдешевле

Рабочий сайт: собрал корзину в магазине → увидел, где этот же набор дешевле офлайн или с доставкой.

Открыть: https://eneonstudio-dev.github.io/tamdeshevle/

## Сейчас умеет

- Москва / Санкт-Петербург — разные учебные цифры из `prices.json`
- Пятёрочка, Магнит, Перекрёсток, Лента, Дикси
- Доставка: Лавка и Впрок
- Корзина, сравнение, разбивка «почему так»
- Тумблер «сходить / привезти»
- Сохранение корзины в браузере

Цены учебные, не ценник полки. Живая полка без адреса точки сайтами сетей не отдаётся.
